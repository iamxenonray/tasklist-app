# Information

**Programming Language:** C++ (C++20)

**Visual Studio Version:** Visual Studio 2022

**Opening Instructions:**

To open and run:

If Visual Studio is installed, click the .sln file to open the project in Visual Studio. If using a version other than 2022, it *should* open, but it may give you a prompt about a Visual Studio pack(?) version mismatch. If your VS version is after 2022 it should be fine to not upgrade the version and continue, if your VS version is before 2022 it may be a good idea to downgrade the version before continuing. Once you are in, click the Local Windows Debugger at the top to run.

If you only wish to inspect the code without running the program, you can open the .h and .cpp files directly on whatever text editor you have.

If you only wish to run the program, a .exe file has been provided ("TaskListApp.exe").

For testing information, please see the dedicated testing document ("TaskList Test Plan.docx") located in the same directory as this README.
